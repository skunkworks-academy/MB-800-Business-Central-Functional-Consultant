Business Central Functional Consultant

A practical, lab-led course for functional consultants implementing Business Central. The course is hosted inside Skunkworks Academy with local module pages and a local lab viewer—no course-content redirect to Microsoft-hosted pages.

Start Module 01 Browse all modules

Course structure

Five modules. One implementation journey.

Progress from environment setup and company configuration through financials, trade, transactions, Copilot and finance reconciliation.

Hands-on laboratory

26 labs hosted inside this course.

Every lab opens in the Skunkworks Academy local viewer and renders the exercise directly from this repository.

Role alignment

Built around the MB-800 functional consultant role.

Use the course to practise company setup, user and profile management, data migration, workflow configuration, financial setup, purchasing, sales, inventory, journal processing, reconciliation and Copilot-enabled scenarios.

Delivery model

Self-contained Skunkworks Academy course experience.

The module pages, navigation and lab viewer remain on the Skunkworks Academy GitHub Pages site. Source exercises are read directly from the repository rather than sending learners to the upstream Microsoft-hosted lab site.
